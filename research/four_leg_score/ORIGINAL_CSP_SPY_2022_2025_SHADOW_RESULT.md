## 2. 唯一进行的历史代理实验

为回答“原版只有卖 Put 时 SPY 历史表现如何”，本轮仅复现原版**有历史公共数据可观测的部分**（不调整参数迎合结果），其余完全公开标记为代理、缺失或不能验证：

| 条件 | 原版正式合同 | 此次代理 |
|---|---|---|
| 标的 / 合约方向 | 单账户 CSP，选 Put | SPY / Put，单标的 |
| 抽样 | 实时策略按交易时段运行 | 每月第一个有期权报价的周三，每年最多 12 次，**不是原版的真实逐日候选序列** |
| 到期天数 | DTE 7–60（默认） | 完整使用 7–60 个日历日；必须当年内到期，减少到期结果缺失 |
| Strike 召回 | strike ≤ 实时报价现价，默认下边 80% | 以当日日终股票 close 代理现价，K/S ∈ [0.8,1.0]，不冒充盘中 |
| 盘口 | OpenD bid>0，ask≥bid，spread/mid≤40% | 按历史期权 bid/ask 过滤，相对 spread≤40%；无逐条真实同步报价时间 |
| 波动率 | IV/term-matched RV≥1.10 **且** IV−RV≥0.05 | 两条同值门槛；RV 用观察日前完成的历史收盘收益、样本 std×√252；未来剩余交易日数量借历史日历重建，不等于 OpenD 正式 QFQ 与原版交易日历 |
| 收益门槛 | 单合约年化净权利金收益≥10%；净费收益折算至少 CNY50 | 10% 用**未向 tick 向上取整的 raw mid** 和每股 $0.01 示意费估算；CNY50 的历史完整 FX/真实 multiplier/费率缺失，不能重建 |
| 正式收益口径 | 持有期 net_premium / (K×multiplier−net_premium) | 每股 \`(mid−0.01)/(K−mid+0.01)\`，仅代理，不代表实际原版 net_premium |
| 排序 | 持有期净收益先比较；相差≤0.002 同收益区间，先接货折价、spread、OI、净额、合约 ID | 一标的每个观察日仅取一张；按对应代理排序规则，不看未来到期结果 |
| 报价成交 | tick-ceil(mid) 挂限价，不追价，无成交保证 | 结果同时报**Bid 更保守假设成交**与**raw mid 假设成交**；均非实际成交 |
| 担保与事件 | 同物理账户真实现金、FX、新鲜 OpenD 财报日历为必要条件 | **均未提供，不得表示通过；本实验不能证明一笔真仓可开** |
| 最终到期结果 | 真实实际订单及后续交割记录 | 标的到期日最近日终收盘价格作为内在价值代理，不代表真实提前指派/清算 |

**成交价敏感性**：若假定在原版意图使用的 raw mid（**未 tick 四舍五入，且不保证订单成交**）成交，则各年度平均到期 P/L 为 2022 +1.1564、2023 +3.2164、2024 +6.8000、2025 −0.4570 美元/股。两种报价情景均受历史报价来源/同步问题制约。

2025 年有 4/5 次盈利，但平均每股 **亏损 0.486 美元**，最大一笔亏损 41.02 美元/股。说明即便遵守可重建的 IV/RV 双门槛、净权利金门槛，尾部仍可能抵消多笔有限的权利金收入。不要把这 24 次观察当作 24 次独立、已成交或可重复的真实交易结果。

### 解释样本量

- 7–60 DTE 且 K≤现价等基础盘口后初始候选行：2022 9,403，2023 7,035，2024 9,147，2025 8,869。
- 按 IV/RV 双硬门槛与年化收益门槛，以及只能按月份入选，每年最终仍只有 5–7 个日期存在可重建的候选，样本数量极小。
- 缺失账户现金、历史价格 tick、经验证 OpenD 财报日历与真实完整费用，故不能声称“原版策略在 2024 年 100% 赢”或“四年准确率 83%”。
- 即使所有代理条件都通过，真实原版还可能因其他账户/数据硬门槛拒绝，或 mid 限价根本不成交。

## 4. 与 V1 不能直接比较的地方

前一轮四方向 V1 的 “Short Put 59.6%” 是 **245 对** ATM/OTM 合约中，高分合约最终资金归一化收益率高于低分合约的比例；不是 Short Put 的到期盈利率。本轮“原版代理 83.3%”是 **24 个**特定观察日筛选出来的 Put 到期情景是否盈利。两者样本、DTE、行权价、策略与**评价指标全部不同**，不能说 83.3% 大于 59.6% 因而原版更准确。

如果需要原版真实准确率，需要历史 OpenD 真实当时可交易快照、账户有效现金、标准合约和 multiplier、完整 Futu fee/FX、日历/财报和真实订单/指派结果。现有数据不支持给出 1:1 正式准确率。**不能为了生成一个看起来更好的数字而删除这类硬门槛。**
